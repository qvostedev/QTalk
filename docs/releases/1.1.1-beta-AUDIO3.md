# QTalk 1.1.1-beta(3) — LAN2-AUDIO3-MICFIX

- Ordinary and conference call microphone icons are smaller (13×20 dp); the 42 dp buttons and compact widget stay the same size. Muted icons use the same dimensions.
- Ringtone selection now has visible Play/Stop controls. Play previews the whole file at the selected ringtone volume. EOF, Stop, another selection, Save, Cancel, leaving settings, calls and engine shutdown release playback. Delayed loading cannot restart a stopped preview. Imports and their 60-second limit remain available.
- Unknown unsaved numbers have Clear on the left and Add contact on the right in Information. Clear empties the complete dial draft. It is disabled for an empty draft and throughout incoming, dialing, ringing, active and ending calls. Saved-contact Delete/Edit and contact-edit drafts keep their existing behavior.
- Microphone volume defaults to 50%, applying 0 dB (unmodified input). Zero is silent; 100% is bounded at 2x amplitude (+6.02 dB), not the legacy +30 dB. Speaker volume remains attenuation-only, with unity at 100%. Changes ramp smoothly after slider release and save after a short debounce. Manual mute, hold and staged LAN2 leg safety are preserved.
- The separate microphone boost feature, switch and API are removed. Create conference no longer highlights on hover/press. No meter, automatic microphone capture, Windows hardware-volume, AGC or EQ changes are added.

Gain schema 4 maps schema-3 microphone amplitude to half its slider value, preserving attenuation and silence: previous 100% becomes neutral 50%. Legacy settings also migrate, with old 50% becoming neutral 50% and legacy boosts clamped to unity. Obsolete boost preferences are removed. Missing settings and reset use 50% microphone / 100% speaker. Subsequent restarts retain the selected values.

The display version is `1.1.1-beta(3)`; About and the JAR identify `LAN2-AUDIO3-MICFIX`. LAN capability/protocol stays `LAN2`, with the existing handoff diagnostics and conference behavior retained.

Verification uses Compose semantics/rendered bounds, controllable fake playback, PCM samples and synthetic native calls with file audio. Physical microphone/speaker quality, acoustic preview volume, actual installation and multi-PC LAN behavior remain user tests. The installed QTalk and live settings/credentials were not used for validation.
