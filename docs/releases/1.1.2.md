## English

Windows release QTalk 1.1.2.

Changes:

- Fixed filter flicker when switching between Calls and Contacts. Each section now preserves its selected filter.
- Added contact creation directly from a dialed number and improved the information card for unknown numbers.
- Added participant removal with confirmation for group-call creators hosting the call.
- Improved group-call handoff when the host leaves, with direct local-network connections and recovery if preparation fails.
- Fixed microphone gain and volume defaults, improved audio controls and ringtone preview.
- Refined call controls and added a Clear action for dialed numbers.
- Added diagnostic logs for group-call handoff.

## Русский

Релиз QTalk 1.1.2 для Windows.

Изменения:

- Исправлено мигание фильтров при переключении между звонками и контактами. Каждый раздел теперь сохраняет выбранный фильтр.
- Добавлено создание контакта из набранного номера и улучшена карточка неизвестного номера.
- Добавлено удаление участников с подтверждением для создателя группового звонка, пока он остаётся организатором.
- Улучшена передача группового звонка при выходе организатора: прямые соединения по локальной сети и восстановление при ошибке подготовки.
- Исправлены усиление микрофона и уровни громкости по умолчанию, улучшены настройки звука и предпрослушивание рингтонов.
- Доработаны кнопки управления звонком и добавлена очистка набранного номера.
- Добавлены диагностические журналы передачи групповых звонков.
