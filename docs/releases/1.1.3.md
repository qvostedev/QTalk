## English

QTalk 1.1.3 for Windows and Linux.

Technical support:
- Settings → Technical support offers two request types: report a problem or suggest an improvement.
- A problem report includes a cleaned diagnostic ZIP; an improvement is sent without logs.
- Every request gets a number like №00001, identical in the app and the support chat.
- Screenshots are chosen manually and stripped of metadata; there is no automatic screen capture.

Interface:
- Removed the pale hover overlay from Material controls.
- Added a GitHub button in About.

## Русский

Релиз QTalk 1.1.3 для Windows и Linux.

Техподдержка:
- В настройках есть «Техническая поддержка» с двумя типами обращения: проблема или улучшение.
- К проблеме прикладывается очищенный ZIP с диагностикой; предложение — без журналов.
- У обращения есть номер вида №00001 — одинаковый в приложении и чате поддержки.
- Скриншот выбирается вручную и очищается от метаданных, автосъёмки экрана нет.

Интерфейс:
- Убрана светлая подложка при наведении на элементы.
- В «О приложении» добавлена кнопка GitHub.
