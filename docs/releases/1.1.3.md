## English

QTalk 1.1.3 for Windows and Linux.

### Technical support inside QTalk

- Added **Settings → Technical support** with a title, description, optional PNG/JPEG screenshot and two request types: **report a problem** or **suggest an improvement**.
- A problem report automatically includes a bounded, cleaned diagnostic ZIP. An improvement suggestion is sent without any logs or system information.
- Added readable ticket numbers such as **№00001**, shown both in QTalk and the support chat.
- Added progress and error messages, draft retention during the app session and protection against duplicate submissions. An uncertain retry reuses the original report.
- Screenshots are selected manually and re-encoded without their original metadata. QTalk does not capture your screen automatically.
- Diagnostics include only selected QTalk log files and limited system metadata. Sensitive values are filtered; account databases, contacts and recordings are not collected.

### Interface

- Removed the pale default hover overlay from Material controls in both light and dark themes, keeping QTalk's own selection styles.
- Added a GitHub button in About that opens the project page in the browser.

Available packages: Windows installer, Ubuntu 24.04 / Debian 13 DEB (amd64), and the native NixOS application archive (x86_64-linux). Existing Nix installation and update instructions remain unchanged.

## Русский

QTalk 1.1.3 для Windows и Linux.

### Техподдержка прямо в QTalk

- Добавлен раздел **Настройки → Техническая поддержка**: заголовок, описание, необязательный скриншот PNG/JPEG и два типа обращения — **сообщить о проблеме** или **предложить улучшение**.
- К обращению о проблеме автоматически прикладывается ограниченный очищенный ZIP с диагностикой. Предложение об улучшении отправляется без журналов и сведений о системе.
- Добавлены понятные номера обращений вида **№00001** — одинаковые в приложении и чате поддержки.
- Добавлены этапы отправки, сообщения об ошибках, сохранение черновика до закрытия приложения и защита от повторной отправки. При неопределённом результате повтор использует исходный отчёт.
- Скриншот выбирается только вручную и очищается от исходных метаданных. Автоматической съёмки экрана нет.
- В диагностику попадают только выбранные журналы QTalk и ограниченные сведения о системе. Чувствительные значения фильтруются; базы аккаунтов, контакты и записи разговоров не собираются.

### Интерфейс

- Убрана светлая стандартная подложка при наведении на Material-элементы в тёмной и светлой теме. Собственные стили выбора QTalk сохранены.
- В разделе «О приложении» добавлена кнопка GitHub со ссылкой на страницу проекта.

Пакеты: установщик Windows, DEB для Ubuntu 24.04 / Debian 13 (amd64) и архив приложения для NixOS (x86_64-linux). Способы установки и обновления через Nix остаются прежними.
