QTalk — open-source кроссплатформенный SIP-клиент с упором на быстрый и современный интерфейс, гибкую настройку и единый пользовательский опыт на настольных и мобильных платформах.

Цель проекта — создать современный и настраиваемый софтфон, сохранив приложение открытым и независимым от конкретной платформы.

## Статус

> **Ранняя стадия разработки**

QTalk находится в активной разработке и пока не предназначен для повседневного или production-использования.

Базовая архитектура приложения и абстракция VoIP уже реализованы. SIP-функциональность и интеграция Linphone SDK находятся в разработке.

## Архитектура

QTalk отделяет логику приложения от конкретной реализации VoIP.

```text
              QTalk
                │
       ┌────────▼────────┐
       │       UI        │
       │    Compose MP   │
       └────────┬────────┘
                │
       ┌────────▼────────┐
       │    ViewModel    │
       └────────┬────────┘
                │
       ┌────────▼────────┐
       │     Domain      │
       │    Use Cases    │
       └────────┬────────┘
                │
       ┌────────▼────────┐
       │   VoipEngine    │
       │    абстракция   │
       └────────┬────────┘
                │
       ┌────────▼────────┐
       │Linphone adapter │
       └────────┬────────┘
                │
       ┌────────▼────────┐
       │  Linphone SDK   │
       └─────────────────┘
```

Общий код разделён на несколько основных слоёв:

```text
shared/
└── src/commonMain/
    └── kotlin/com/qvoste/qtalk/
        ├── app/        # Инициализация приложения и зависимостей
        ├── data/       # Источники данных и хранение
        ├── domain/     # Логика приложения и use cases
        ├── ui/         # Compose UI и ViewModel
        └── voip/       # Независимая от платформы абстракция VoIP
```

Интерфейс `VoipEngine` отделяет приложение от конкретной реализации SIP. Благодаря этому общая логика QTalk может работать с VoIP-функциями без прямой зависимости от API Linphone.

Платформенная интеграция Linphone будет реализована за этой абстракцией.

## Лицензия

QTalk — open-source проект.

Для проекта планируется использование лицензии **GNU AGPLv3** с учётом лицензирования open-source версии Linphone SDK.

Окончательная лицензия проекта и информация о сторонних компонентах будут добавлены после интеграции конкретной версии Linphone SDK.
